# Cloned_voice_responder
This project aims make a assistant to train on a voice which will be used to respond to the user when asked question or prompted to.
It is a nlp project that takes in text as input and give answer in voice that is trained, to sound like a person whose voice is given as training data.

# Tools used
GORQ:- for the LLM model which is responcible for the answers.
COQUI XTTS V2 :- This is used to actually clone the voice that is given which runs on GPU

This is a *GPU* centric code.
